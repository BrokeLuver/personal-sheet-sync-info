Privacy policy

This policy describes the personal spreadsheet utility, operated by its owner.

Last updated: 11 November 2026

Information used

The utility reads values from a configured range in an authorized Google spreadsheet. Sources may include synthetic test files and operational spreadsheets explicitly selected by the owner. It also uses Google OAuth credentials and credentials for the owner's destination storage account.

The requested Google permission is drive.file, which permits access to specific files created with or explicitly authorized for the application. The sync reads spreadsheet values; the initial test setup creates a synthetic spreadsheet.

Purpose and transfers

Spreadsheet values are processed to validate the source and produce an XLSX export in the owner's designated cloud storage. This transfer is the tool's purpose. The tool does not use the data for advertising, sell it, or train machine learning models with it.

The owner controls the source account, execution environment and destination account. Google and the destination storage provider process requests under their own terms and privacy policies.

Storage and logs

OAuth and storage credentials are kept in the owner's private secret store. During execution, temporary credential files are restricted to the runtime user and removed after the operation. Credential values and spreadsheet rows are not included in the utility's normal logs.

Normal execution logs contain status, row counts and a content checksum. The separate synthetic test may also log aggregate synthetic amounts. The destination retains the latest exported workbook; the storage provider may also retain versions or operational records. The owner controls deletion and retention settings in those systems.

Revocation and deletion

The owner can stop scheduled execution and revoke the application's Google access from Google Account connections. Revocation does not delete previously exported files or logs. Those must be deleted separately from the destination storage and execution environment, including any retained versions.

This website

These static information pages contain no sign-in form, application analytics, advertising or tracking scripts. Their source does not contain account credentials or spreadsheet contents.

If hosted on GitHub Pages, GitHub processes technical requests under the GitHub Privacy Statement. That hosting is separate from the sync's private execution environment.

Contact and updates

For questions about this personal utility, use the support email shown on Google's consent screen. This policy should be updated before the tool's data sources, recipients or uses materially change.
