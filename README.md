# Sheets Sync information pages

Static description and privacy policy for the owner's personal synthetic sync test.
The website consists only of `index.html`, `privacy.html`, `styles.css` and `.nojekyll`.
No sync implementation, credentials, configuration, source identifiers or data
belong in this repository.

These pages were prepared as a private draft. GitHub Pages publication requires
the owner's approval of public access: a private repository does not make the
resulting Pages site private. `noindex` is an indexing preference, not access
control. The Google OAuth
information pages must be reachable without signing in.

Review the content, hosting disclosure and support contact before publication.
Publish only these static website files from the chosen Pages source. Keep the sync
implementation and runtime configuration in their existing private environments.
