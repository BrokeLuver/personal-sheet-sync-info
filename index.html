Sheets Sync Synthetic Test

A personal tool for exporting an authorized Google spreadsheet to an XLSX file in the owner's cloud storage.

What the tool does

The owner runs the utility in a private computing environment. It reads a bounded spreadsheet range, checks its structure and values, and updates a designated XLSX file when the contents change.

The current deployment uses a test spreadsheet containing synthetic data. This site is an information page; it does not run the export or offer a public service.

Google access

The utility requests the drive.file permission. Google describes this as access to see, edit, create and delete only the specific Drive files used with the app. It does not provide access to every file in an account.

The sync operation reads Google Sheets data. The initial test setup also creates a synthetic spreadsheet. The owner controls the Google authorization and the destination storage account.

Privacy and contact

Read the privacy policy for the information used, storage and access controls. For questions, use the support email shown on Google's consent screen for this application.
